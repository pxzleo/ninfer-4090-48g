# NInfer Control UI

本机轻量监控与配置界面，默认绑定 `127.0.0.1:8081`。它不依赖第三方 Python 包，读取 NInfer 的
`/health`、`/metrics`、`/slots`、`/v1/models`，并补充 Docker 日志和 `nvidia-smi` 数据。

## 启动

从项目根目录执行：

```bash
python3 ninfer_ui/server.py
```

然后打开 <http://127.0.0.1:8081>。可用环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `NINFER_UI_TARGET` | `http://127.0.0.1:8080` | NInfer 服务地址 |
| `NINFER_UI_COMPOSE` | 项目根目录 `compose.yaml` | 可管理的 Compose 文件 |
| `NINFER_UI_CONTAINER` | `ninfer-4090` | Docker 容器名 |
| `NINFER_UI_SERVICE` | `ninfer` | Compose 服务名 |
| `NINFER_UI_HISTORY` | `ninfer_ui/history.sqlite3` | 吞吐历史数据库路径 |
| `NINFER_UI_LAN_API` | 使用目标地址 | 状态页显示的局域网 API 地址；前端会把回环主机改写为当前 UI 主机 |
| `NINFER_UI_ALLOW_LAN` | 未设置 | 设为 `1` 后允许绑定 `0.0.0.0` 并接受私网管理请求 |
| `NINFER_UI_PUBLIC_HOST` | 未设置 | LAN 模式允许的浏览器 Host / Origin，例如 `192.168.100.190` |

默认模式拒绝绑定非回环地址。只有 `NINFER_UI_ALLOW_LAN=1`、`NINFER_UI_PUBLIC_HOST` 是 RFC1918
IPv4 且监听地址为 `0.0.0.0` 时才启用 LAN 模式。管理操作要求 RFC1918 TCP 对端、匹配的 Host 和
Origin、JSON Content-Type 及确认短语。Windows `portproxy` 会把原始客户端地址隐藏成 WSL 网关，
因此经转发访问时，真实来源范围必须由 Windows 防火墙限制；本机部署使用 Private Profile、
LocalSubnet、TCP 8081 和指定 WLAN 地址。LAN 模式没有账号认证，只应在可信局域网中使用。

## 功能

- 界面支持中文和英文；默认跟随浏览器首选语言，也可在顶部手动选择，手动选择会保存在当前浏览器中；
- 状态页按服务端 2 秒统计窗口刷新实时吞吐、预填充、运行/排队数量和平均 batch；最后一条吞吐统计超过 2.5 个统计窗口后按无活动处理，不会继续显示旧速度；
- 吞吐趋势提供实时、天、周、月范围；鼠标悬停或触屏点击图表可查看本地时间、解码和预填充的均值与峰值；天、周、月不显示底部导航条、“当前显示”和快捷时段控件，可直接使用图内滚轮或触控缩放；实时保存最近 5 分钟，完整历史周期按自然日、自然周、自然月展示；周视图横轴固定覆盖周一到周日，完整周使用星期刻度，放大到两天以内时显示“星期 + 时间”，尚未发生的区间保持空白；其他当前周期只显示到服务端采集时刻；长期历史以 1 分钟“均值 + 峰值”保存，完整周期按 5 分钟、10 分钟和 2 小时概览，放大后按可见窗口自动读取更细粒度数据（最多约 1440 个聚合桶）；图上只绘制均值水平区间，峰值保留在悬停详情中，不再用散点或连线制造视觉噪声；历史保留最近 400 天并在 UI、NInfer 重启后继续读取；
- 实时范围把每个原始 2 秒样本显示为水平保持区间，并在下一个样本到达时阶梯切换；刷新时按采样时间稳定关联数据点，纵轴按当前 5 分钟窗口重新计算：上限不变时已有曲线只向左平移，上限变化时瞬时切换尺度而不做上下插值；采集中断处保持断线，不用斜线推测两个样本之间的吞吐变化；
- 天、周、月在缩放后切换聚合粒度时直接替换整组数据，不对不同时间位置、不同点数的数据集执行形变动画，避免切换过程中绘制不存在的斜线；
- 实时运行标题区同步显示累计请求、累计输出和累计输入；
- MTP 接受率、缓存复用命中率与 token 数、累计输入/输出；
- 各执行槽的预填充上下文比例、独立解码速度、等待阶段和按物理页统计的 Main KV 驻留量；各槽驻留量之和与总缓存占用一致；
- 显示包含空闲槽保留缓存的 Main KV 总占用、共享容量与使用百分比；
- GPU 利用率、显存、温度、功耗和时钟，以及按当前 UI 访问主机名生成的局域网 API 地址和实时模型名；
- 最近完成请求固定保留并完整显示最新 50 条，数据写入历史数据库，UI 重启或吞吐日志滚动后仍保留；点击或用键盘打开请求详情页，可查看完成时间、输入输出、缓存命中、TTFT、预填充/解码速度、结束原因、MTP 数据、真实连接地址、User-Agent、可选客户端/Agent/会话标识和原始完成日志；不记录 API Key，也不采用 `X-Forwarded-For`；
- 原始服务日志展开后每 2 秒刷新，并自动定位到最后一行；
- `compose.yaml` 白名单字段编辑和校验，点击“保存配置”后直接写入；
- 保存前生成 `ninfer_ui/backups/` 备份并用 revision 防止覆盖外部修改；
- 配置页提供 Qwen3.8 关闭/低/中/高思考等级，以及默认关闭的“中文思考”开关；开启中文思考写入 `--reasoning-language zh-CN`，关闭时移除该参数并恢复模板默认语言行为。历史 reasoning 始终由“保留历史思考”对应的 `--preserve-thinking` 独立控制。思考等级关闭时不写入思考语言。开关说明为“新建会话生效”。页面同时提供 NInfer 启动、停止和重启控制，停止与重启使用普通确认框，启动和重启会等待 `/health` 恢复。
- 中文思考引导与历史 reasoning 保留彼此独立；“保留历史思考”开启时继续带入历史 reasoning，关闭时不带入。
- 配置页可按本地自然日期清除吞吐历史，起止日期均包含，删除前需要输入确认短语；

保存配置不会自动重启服务，修改配置需保存并重启后生效。单独执行“启动 NInfer”或“重启 NInfer”后，新启动配置才会生效；停止和
重启会中断正在运行的推理请求。

吞吐图表使用随 UI 本地分发的 Apache ECharts 6.1.0，不依赖外部 CDN；许可证与第三方声明见
`ninfer_ui/static/ECHARTS-LICENSE.txt`、`ninfer_ui/static/ECHARTS-NOTICE.txt`、
`ninfer_ui/static/licenses/LICENSE-d3.txt` 和 `ninfer_ui/static/licenses/LICENSE-zrender.txt`。
